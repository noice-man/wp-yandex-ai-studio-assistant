# Yandex AI Studio Assistant for WordPress

**Версия:** 1.1.0  
**Автор:** Valery Molodtsov  
**Страница плагина:** [ворд-пресс.рф](https://ворд-пресс.рф/plugins/yandex-ai-studio-assistant/)  
**Исходный код:** [GitHub](https://github.com/noice-man/wp-yandex-ai-studio-assistant)  
**Инструкция:** [настройка Yandex AI Studio в WordPress](https://ворд-пресс.рф/solutions/yandex-ai-studio-wordpress-setup/)  
**Лицензия:** GPL-2.0-or-later.

WordPress-плагин для работы с моделями из Yandex AI Studio прямо из админки: анализ опубликованных материалов, обсуждение контента, подготовка новых записей и редактирование существующих с подтверждением администратора. Нет внешних JS-библиотек, публичных API и автономной публикации.

## Установка

1. WordPress → Плагины → Добавить плагин → Загрузить ZIP.
2. Активируйте и откройте **Yandex AI** в меню слева.
3. Получите API-ключ в [Yandex AI Studio](https://aistudio.yandex.ru/) и Folder ID каталога.
4. На вкладке **Подключение** задайте Folder ID, секретный API-ключ и модель из выпадающего списка (по умолчанию `yandexgpt-5.1`).
5. Нажмите **Проверить подключение** — это реальный оплачиваемый запрос в API.
6. На вкладке **ИИ-помощник** задайте режим, материал и задачу.

Пошаговая инструкция, включающая права сервисного аккаунта и получение ключа: [ворд-пресс.рф](https://ворд-пресс.рф/solutions/yandex-ai-studio-wordpress-setup/). Работа со структурированными CPT и ACF: [отдельное руководство](https://ворд-пресс.рф/solutions/yandex-ai-studio-wordpress-acf-cpt/).

## Режимы

- **Чат с контекстом сайта**: последний контент либо найденные опубликованные записи; история переписки живёт только в текущей вкладке браузера (последние три пары реплик).
- **Анализ контента**: выборка до 16 опубликованных записей и страниц; выявление пробелов, дублей, SEO-проблем — рекомендации модели требуют проверки.
- **Создание записи**: модель формирует title, slug, excerpt, HTML-контент и Yoast SEO title/description/focus keyphrase. Видимый предпросмотр; запись появляется как черновик только после отдельного подтверждения.
- **Редактирование**: выбрать конкретную запись. Черновики/ожидающие одобрения обновляются по подтверждению; опубликованные/запланированные сохраняются **отдельным черновиком**. Исходная страница не меняется.

Плагин не публикует, не удаляет, не меняет настройки или пользователей по команде модели. Это **административный ассистент**, а не внешний MCP-сервер для других приложений.

## Версия 1.1 — контракт сайта (CPT / ACF / темы / плагины)

В админке **Yandex AI → ИИ-помощник** укажите **тип контента (CPT)**. Кнопка «Посмотреть контракт выбранного типа» покажет JSON со следующими сведениями:

- Зарегистрированные типы записей, редакторские возможности (title/editor/thumbnail), таксономии и до 30 существующих терминов в каждой.
- Группы ACF, прямо привязанные к выбранному типу контента: ключи, имена, типы, подписи, required, choices, инструкции, диапазоны чисел.
- Метаполя CPT, зарегистрированные с `show_in_rest` и безопасными именами. **Они отображаются только для чтения**; запись в произвольные метаполя отключена.
- Название активной темы, доступные названия шаблонов и список активных плагинов (без конфигурации, исходников и ключей).
- Добровольно опубликованные разработчиками дополнительные контрактные правила через фильтр `wpr_yai_extra_contract`.

Схема передаётся в Yandex AI Studio **только после явного запроса и согласия**. Значения простых ACF-полей передаются только для конкретно выбранной записи, а не при массовом анализе.

**Поддерживаемая запись в ACF:** `text`, `textarea`, `wysiwyg`, `number`, `true_false`, одноэлементные `select` и `radio`. Имена полей сверяются с реально найденной группой и типом; значения и варианты списков валидируются. Введённые ИИ термины таксономий принимаются только по существующим ID. Сложные ACF (`repeater`, `flexible_content`, `gallery`, `relationship`, `group` и т.п.) **только описываются**, но не записываются. Даже для простых полей полноценность созданного CPT следует проверять вручную — сторонняя тема или плагин могут требовать скрытых обязательных полей.

### Добавление явного контракта своей темой/плагином

Если часть контрактов не представлена в ACF/`register_post_meta` или задаётся бизнес-логикой темы, разработчик может добавить описание через безопасный фильтр:

```php
add_filter( 'wpr_yai_extra_contract', function ( $rules, $post_type ) {
    if ( 'portfolio' === $post_type ) {
        $rules['portfolio'] = array(
            'template_notes' => 'В карточке обязательно заполнить hero_title и краткое описание.',
            'editorial_rules' => 'Не придумывать количественные результаты проектов.',
        );
    }
    return $rules;
}, 10, 2 );
```

Фильтр задаёт **контекст/инструкции**, но не открывает ИИ произвольную запись метаданных. Не помещайте в него секреты, приватные настройки или персональные данные. Это не статический анализ PHP/JS темы или кода плагинов.

### Выбор моделей и тарификация

В **Подключение** доступен выбор Alice AI LLM / Flash, YandexGPT Pro 5.1 / Lite 5, Qwen3.6, DeepSeek V4 Flash / V4.1 и GPT-OSS 120B (с предупреждением об окончании поддержки). Назначение каждой модели и окно контекста отображаются рядом с выбором. Для нестандартной модели предусмотрен ручной ID. Кнопка **«Показать доступные модели каталога»** обращается к `GET /v1/models` после сохранения API-ключа (может требоваться область `yc.ai.models.viewer`).

Официальные ссылки: [действующие тарифы](https://aistudio.yandex.ru/ru/docs/ai-studio/pricing), [поддерживаемые модели и срок жизни](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models). Цены в плагине намеренно не фиксируются, поскольку Яндекс может их изменять. Подписка AI Studio и тарификация API — разные сценарии.

## API и модели

Использует OpenAI-совместимый **Yandex AI Studio Chat Completions API**: `POST https://ai.api.cloud.yandex.net/v1/chat/completions`, заголовки `Authorization: Api-Key ...` и `OpenAI-Project: <folder-id>`, модель `gpt://<folder-id>/<model-id>`.

Сервисный аккаунт должен иметь `ai.languageModels.user`, ключ — область действия `yc.ai.foundationModels.execute`. API-вызовы и стоимость регулируются тарифами Яндекса. Явный выбор другой модели возможен, только если она доступна каталогу и поддерживает Chat Completions. Структурированный ответ запрашивается через JSON Schema с резервным режимом на моделях без поддержки схемы.

### Хранение ключа

API-ключ не попадает в JavaScript, HTML или публичные REST-ответы. При сохранении через админку он шифруется AES-256-GCM с производным ключом от солей WordPress; опция не загружается автоматически. Если OpenSSL недоступен, секрет можно настроить через `wp-config.php`:

```php
define( 'WPR_YAI_API_KEY', 'ваш-секретный-api-ключ' );
define( 'WPR_YAI_FOLDER_ID', 'id-вашего-каталога' );
define( 'WPR_YAI_MODEL', 'yandexgpt-5.1' );
```

Поместите константы выше строки `/* That's all, stop editing! */`. Никогда не размещайте реальные ключи в репозитории GitHub. При изменении солей WordPress зашифрованный ранее ключ потребуется ввести заново.

## Передача данных, безопасность

- Только `manage_options` (администраторы); AJAX и POST-запросы защищены WordPress nonce.
- Данные отправляются **непосредственно с сервера WordPress в Yandex AI Studio**. Администратор подтверждает передачу текста перед запросом.
- Для невыбранных материалов анализируется ограниченная выборка **только опубликованных** записей выбранного CPT; выбранную запись можно анализировать и в состоянии черновика.
- Модель получает текстовые выдержки, а не доступ к БД, файловой системе или WordPress REST API.
- Сохранение черновиков возможно только после подтверждения; данные предпросмотра хранятся на сервере до 30 минут. Контент HTML очищается `wp_kses_post`.
- У ответов могут быть ошибки и выдуманные факты: проверяйте источники, внутренние ссылки, юридические и медицинские сведения.
- Не передавайте персональные данные, конфиденциальные записи и ключи в запросах к стороннему сервису.
- Долгие запросы к модели могут упереться в PHP/nginx таймауты; лимит ответа 5000 токенов.
- Yoast SEO **не обязателен**: метаданные записываются в стандартные Yoast postmeta; без самого Yoast они не влияют на публичное SEO.

## Ограничения MVP

Работа через админку, без внешнего агентского доступа, массового фонового обхода сайта, медиазагрузки, автоматического создания новых терминов, публикации по расписанию, отмены по кнопке и потокового ответа. Для анализа полного большого сайта потребуется отдельный индексатор.

## Проверки

Проверены PHP-синтаксис, структура ZIP, безопасный разбор JSON-кандидата и формирование запросов (тестовые заглушки API). Реальное подключение к Yandex AI Studio, WordPress + Yoast и публикация на пользовательском сайте должны быть проверены на стенде с вашим API-ключом.

Официальные источники: [быстрый старт](https://aistudio.yandex.ru/ru/docs/ai-studio/quickstart/), [API-ключ](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/get-api-key), [Chat Completions](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/generation/completions-basic), [структурированные ответы](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/generation/completions-structured).
