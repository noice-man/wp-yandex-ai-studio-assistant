# Yandex AI Studio Assistant для WordPress

Бесплатный WordPress-плагин для подключения моделей **Yandex AI Studio** к административной панели: чат с контекстом сайта, редакторский анализ, создание SEO-черновиков и подготовка изменений существующих записей.

**Версия:** 1.1.0 · **Автор:** Valery Molodtsov · **Лицензия:** GPL-2.0-or-later · **WordPress:** 6.0+ · **PHP:** 7.4+.

## Основные возможности

- Подключение к Chat Completions API Яндекса через секретный API-ключ и Folder ID.
- Alice AI LLM/Flash, YandexGPT, Qwen, DeepSeek и пользовательские совместимые модели.
- Анализ материалов сайта и генерация новых записей с Yoast SEO-полями.
- Определение CPT, ACF, таксономий, зарегистрированных метаполей и схемы шаблонов.
- Поддержка безопасного заполнения простых полей ACF.
- Предпросмотр всех предлагаемых изменений и сохранение **только после подтверждения администратора**.
- Опубликованные материалы не меняются автоматически: для них создаются отдельные черновики.

Модели могут допускать ошибки; проверяйте содержание и корректность заполнения полей. Запросы к AI Studio тарифицируются отдельно.

## Установка и настройка

Установите ZIP плагина через **Плагины → Добавить новый → Загрузить плагин**. После активации откройте **Yandex AI → Подключение**, введите Folder ID и API-ключ, выберите модель, сохраните настройки и проверьте соединение.

В разделе **Yandex AI → ИИ-помощник** выберите тип контента, проверьте контракт, сформулируйте задачу и подтвердите передачу контента модели. Для генерации тщательно проверьте предпросмотр и нажмите **«Создать черновик»**.

Плагин не публикует записи и не меняет файлы темы самостоятельно.

## Приватность

Плагин передаёт выбранный администратором текст в Yandex AI Studio. Не передавайте секреты и персональные данные. API-ключ хранится на сервере в зашифрованном виде при использовании настроек (или через константу `WPR_YAI_API_KEY` в `wp-config.php`).

См. [официальную документацию Yandex AI Studio](https://aistudio.yandex.ru/ru/docs/ai-studio/quickstart/).
