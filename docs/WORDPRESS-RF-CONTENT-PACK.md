# Контент-пакет для ворд-пресс.рф

Импорт через `wordpress-rf-content-types`: **Инструменты → Импорт контента — ворд-пресс.рф**.

Файл пакета: [content-pack ZIP](https://github.com/noice-man/wp-yandex-ai-studio-assistant/raw/refs/heads/main/dist/yandex-ai-studio-assistant-wordpress-rf-content-pack-v1.1.0.zip).

Материалы и URLs:

- [Карточка плагина](https://ворд-пресс.рф/plugins/yandex-ai-studio-assistant/)
- [Инструкция по подключению](https://ворд-пресс.рф/solutions/yandex-ai-studio-wordpress-setup/)
- [Работа с CPT и ACF](https://ворд-пресс.рф/solutions/yandex-ai-studio-wordpress-acf-cpt/)

Для карточки установлен `is_own_plugin: true`. Внимательно проверьте материал в предпросмотре импортёра. Публикация в WordPress выполняется вручную.
