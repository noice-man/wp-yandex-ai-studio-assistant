# Настройка Yandex AI Studio Assistant

1. Откройте [Yandex AI Studio](https://aistudio.yandex.ru/) и войдите в аккаунт.
2. Создайте или выберите каталог Yandex Cloud с активным платёжным аккаунтом.
3. Создайте API-ключ средствами AI Studio. Сохраните **секретное значение** сразу: повторно посмотреть его нельзя.
4. Если используется свой сервисный аккаунт, нужны права `ai.languageModels.user` и область действия ключа `yc.ai.foundationModels.execute`.
5. Скопируйте Folder ID каталога, которому принадлежит сервисный аккаунт.
6. В админке WordPress в разделе **Yandex AI → Подключение** вставьте Folder ID и API-ключ. Выберите модель из каталога с пояснением и ссылкой на тарифы либо укажите ручной ID. При необходимости нажмите «Показать доступные модели каталога» (для проверки каталога нужен scope `yc.ai.models.viewer`).
7. Нажмите «Сохранить», затем «Проверить подключение». Запрос оплачивается по тарифам Yandex Cloud.
8. Перейдите на вкладку **ИИ-помощник**, выберите тип записи (CPT), посмотрите его контракт (включая ACF), выберите задачу и подтвердите передачу выбранного текста.
9. Для генерации/редактирования тщательно проверьте SEO, выбранные термины, ACF-поля и фактологию результата, только затем нажмите «Сохранить черновик».
10. Откройте созданную запись и при необходимости опубликуйте вручную.

**Важно:** эта интеграция запускает AI через WordPress, а не подключает удалённого ИИ-агента к WordPress. Не публикуйте свой ключ и не передавайте секреты в промптах.

Официальная документация: https://aistudio.yandex.ru/ru/docs/ai-studio/quickstart/

Страница инструкции: https://ворд-пресс.рф/solutions/yandex-ai-studio-wordpress-setup/

## Что известно ИИ о сайте

Плагин строит описание CPT, их таксономий и доступных терминов, зарегистрированных метаполей, ACF и шаблонов активной темы. Значения ACF передаются лишь для отдельно выбранного материала. Для создания и обновления черновиков поддерживаются простые типы ACF; вложенные коллекции и медиа-поля не сохраняются автоматически.
